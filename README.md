# הסקילים של אייל ל-Claude

זה המאגר (repository) של הסקילים שפיתחתי ל-Claude — מקור האמת והגיבוי המסודר שלהם.
כל שינוי בסקיל עובר דרך כאן, כך שתמיד יש היסטוריית גרסאות ואפשר לחזור אחורה.

## מה יש כאן

| סקיל | מה הוא עושה | מתי הוא נכנס לפעולה |
|---|---|---|
| [fable-method](skills/fable-method/SKILL.md) | שיטת עבודה ממושמעת: להבין את המשימה לפני שנוגעים, לבדוק עובדות במקום לנחש, לעבוד בצעדים קטנים ומאומתים, ולא להכריז "מוכן" בלי להריץ | בתחילת כל משימה לא-טריוויאלית, כשהעבודה מסתבכת, ולפני שמכריזים שמשהו גמור |
| [vola-code-check](skills/vola-code-check/SKILL.md) | בדיקת קוד עמוקה בכמה מעברים: מריצה את הקוד באמת, מחפשת באגים לוגיים שקטים, בודקת RTL ועברית, ומדווחת בעברית פשוטה עם תיקונים מוכנים להדבקה | כל בקשה לבדוק / לעבור על קוד, לפני משלוח כלי ללקוח, ואחרי קוד שחוזר מ-Lovable |

## מבנה התיקיות

- `skills/` — קוד המקור של כל סקיל: `SKILL.md` (ההוראות עצמן), `references/` (חומרי עזר), `scripts/` (סקריפטים), `evals/` (מבחני איכות ששימשו בפיתוח)
- `dist/` — קובצי `.skill` ארוזים, מוכנים להעלאה ל-Cowork / claude.ai

## איך מתקינים

**ב-Claude Code על המחשב** — מעתיקים את תיקיית הסקיל אל תיקיית הסקילים האישית:

<div dir="ltr">

```
~/.claude/skills/fable-method/
~/.claude/skills/vola-code-check/
```

</div>

**בפרויקט ספציפי** — מעתיקים אל `.claude/skills/` בתוך תיקיית הפרויקט, והסקיל יהיה זמין לכל מי שעובד על הפרויקט הזה.

**ב-Cowork / claude.ai** — מורידים את קובץ ה-`.skill` מתיקיית `dist/` ומעלים אותו במסך היכולות (Capabilities → Skills).

## איך מעדכנים סקיל

1. עורכים את הקבצים בתוך `skills/<שם-הסקיל>/`
2. אורזים מחדש את קובץ ה-`.skill` (זה סתם קובץ ZIP עם סיומת אחרת): דוחסים את תיקיית הסקיל ומשנים את הסיומת מ-`.zip` ל-`.skill`, ושמים ב-`dist/`
3. עושים commit — וכך נשמרת היסטוריה של כל גרסה

## סקילים שעוד לא כאן

על המחשב (ב-`~/.claude/skills`) מותקנים עוד סקילים שלא נכללו בגיבוי הזה:
vola-seo-audit, vola-design-dna, vola-html-tool, vola-lead-machine-dev, hormozi-advisor.
כשרוצים לגבות גם אותם — מעתיקים את התיקייה שלהם אל `skills/` כאן, באותו מבנה.
