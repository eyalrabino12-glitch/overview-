# STRIVE HIGH — רידיזיין לעמוד הביגוד

רידיזיין לקטגוריית `STRIVE HIGH · ביגוד נוער` באתר כל סטור ישראל
(`catalog.asp?t1=1&t2=4`). קובץ אחד, בלי תלויות, בלי בנייה.

## הרכישה לא נגעה

אין כאן מנוע חנות ואין חלון תשלום משלנו. כל נתיבי הרכישה יוצאים
לאתר החי וממשיכים בזרימה הקיימת. הכול מרוכז באובייקט אחד בראש
ה-`<script>`:

<div dir="ltr">

```js
const SITE = {
  origin  : 'https://kolstoreil.co.il',
  category: '/catalog.asp?t1=1&t2=4',
  basket  : '/catalog.asp?t1=1&t2=4',            // ← נתיב הסל האמיתי
  product : sku => SITE.origin + SITE.category   // ← עמוד המוצר לפי מק״ט
};
```

</div>

כרגע `basket` ו-`product()` מצביעים על עמוד הקטגוריה, כי נתיבי הסל
ועמודי המוצר לא היו זמינים בזמן הבנייה. שתי השורות האלה הן כל מה
שצריך להחליף כדי שהעמוד יעבוד מול המערכת האמיתית — הוספה לסל, סל,
ומשם חלון התשלום הרגיל.

## הנתונים

ארבעת המוצרים, המק״טים והמחירים נלקחו מצילומי מסך של העמוד החי:

| מק״ט | פריט | מחיר |
|---|---|---|
| 10226 | חולצת WORLD | 99 ₪ |
| 10227 | מכנס "WORLD" אפור | 140 ₪ |
| 10232 | חליפה — מכנס וחולצה "WORLD" | 199 ₪ |
| 10233* | חולצת "KRAP" שחורה | 125 ₪ |

\* באתר החי מוצג ל-KRAP המק״ט 10232 — אותו מק״ט של החליפה. זה באג
בצד המערכת; כאן הוקצה מק״ט זמני כדי שהעמוד יהיה עקבי.

תמונות המוצר חולצו מצילומי המסך ומוטמעות כ-`data:` URI בתוך הקובץ,
כדי שהעמוד יעבוד גם בלי גישה לשרת התמונות. להטמעה באתר — להחליף
בשדה `img` של כל מוצר את הכתובת האמיתית.

מידות `S/M/L/XL` הן ברירת מחדל להדגמת המנגנון; אין כאן נתוני מלאי
אמיתיים, ולכן גם אין מצבי "אזל".

## עיצוב

הפלטה נלקחה מהבגדים עצמם — שמנת `#EFEAE1`, שחור דיו `#0C0C0C`,
אפור מלאנז׳, ופליז `#8A6A20` מהמדליון שבאיור של המותג. טיפוגרפיה:
Karantina לעברית, Anton ללטינית, Rubik לגוף הטקסט. פינות חדות,
בלי רדיוסים. תמיכה מלאה במצב בהיר וכהה, RTL, ו-`prefers-reduced-motion`.
